# 推箱子素材编辑器

[English](README.md) | [简体中文](README.zh-CN.md)

为墨水屏推箱子游戏做的两个浏览器端编辑器：一个画人物动作，一个画关卡地图。
都是单文件 HTML，打开就能跑，不装依赖、不用构建、不引框架。

| 文件 | 是什么 |
| --- | --- |
| `character.html` | 人物动作编辑器（28×28 点阵，4 方向 12 帧） |
| `map_editor.html` | 关卡地图编辑器（16×16，自带试玩） |

两个编辑器都只处理数据、不依赖游戏运行，所以也能单独用，或者放进别的项目。

---

## 人物动作编辑器

在 28×28 的点阵上逐像素编辑人物动作，右侧的示意场景可以立刻看到它跑起来的样子。

### 方向与动作

- **4 方向 × 3 动作** — 左、上、下各 4 帧（走 1–2、推 3–4）。右向由左向自动
  镜像，不用重复画。
- **联动规则** — 改左向，右向自动跟着镜像；改上 3、上 4，下 3、下 4 自动垂直翻转。

### 画笔

- **上墨和擦除** — 左键点或拖动上墨，右键点或拖动擦除；按住不放能连续画一整笔。
  画笔有 1 像素和 4 像素两档。选中橡皮后左键也变成擦，同样按这个粗细。
- **套索** — 直接拖是重新框一块；按住 Shift 拖把这一块加进来；按住 Alt 拖把框住的
  这块减掉。画布上只显示加减之后的最终选区，不会留下一堆虚线框。
- **搬动选中的像素** — 在选区里按住拖动，或者用方向键。移动的是「悬浮层」，这些
  像素不会盖住下面已有的内容，下面的东西原样保留。
- **什么时候落笔** — 再点一次套索、换画笔或橡皮、换帧、复制剪切镜像、保存。其余时
  候它一直悬着，可以反复调整。
- 按 Delete（或 Backspace）删掉选区里的像素，选区外的内容不动。

### 一行工具

复制、剪切、粘贴（都按选区实际形状取放）、镜像（会问水平还是垂直）、全选、回退
（`Ctrl + Z` 同样）、复原（回到内置的原始点阵）、保存。

### 在示意场景里直接试

- 在页面任意位置按 ↑ ↓ ← →，右边示意场景里的小人就往前走一步，朝向也跟着变。
  只要画布上有选区，方向键先去搬像素，示意图不动。
- 在示意场景里按住往一个方向拖，松手后小人朝那个方向走一步。拖动距离小于 12 像素
  算点击，不动。

### 切帧

- 同方向连按，交替用第 1 帧和第 2 帧，看起来就是在迈步；停下来从第 1 帧重新起。
- 换方向会重置到该方向的第 1 帧，四个方向各自都有完整的迈步循环。
- 前面是墙或箱子推不动时，人不动，但帧照切——贴着墙挪动时腿不会僵住。
- 推箱子用第 3、4 帧，交替使用，推一段路不会一直是同一个姿势。只要前面贴着箱子就
  一直保持伸手推的样子，即使推不动。
- 箱子推到目标点后变成实心方块加叉的样式；它仍然可以继续推走，推出目标点后那一格
  会恢复成空的目标点。
- 在示意场景里长按约半秒，箱子、目标点、人的位置都复位，方便改完一帧重看效果。

### 保存

保存会把 12 帧写进本地存档，并生成一份可直接替换游戏 `domain/character.lua` 的源码。

## 地图编辑器

在 16×16 的格子上画关卡，画完可以当场试玩，确认这关能通。

### 六个工具

- 地面、墙、目标、箱子、人物、擦除。先点工具再点格子画上去，也可以按 `1`–`6` 直接换。
- **按住拖动** 可以连着画一整条，墙和地面最常用。
- **右键就是擦** — 右键点格子或按住拖，把那几格擦回地面，不用先切工具。触屏设备上
  选「擦除」即可。
- **再点一次取消** — 墙 / 目标 / 箱子这一格已经是同一种，再点一下就变回地面，改错很快。
- **人物只有一个** — 新点一处人物，原来那格自动变回地面。
- **清空是彻底清空** — 连外围那一圈墙一起清掉，一张白纸重画。按错了 `Ctrl + Z` 能撤回来。

### 尺寸固定

固定 16×16，和游戏里的 100 关关卡表同尺寸，导进去不用再换算。

### 快捷键

| 按键 | 作用 |
| --- | --- |
| `1` – `6` | 切换工具：地面 / 墙 / 目标 / 箱子 / 人物 / 擦除 |
| `↑ ↓ ← →` | 编辑时移动光标（方框跟着走）；试玩时是人走一步 |
| `空格` / `Enter` | 在光标那一格画上当前工具 |
| `Delete` / `Backspace` | 把光标那一格擦回地面 |
| `Ctrl + Z` | 撤销一步 |
| `Ctrl + Shift + Z` / `Ctrl + Y` | 重做 |
| `P` | 试玩 / 退出试玩 |
| `W A S D` | 试玩时走一步（和方向键一样） |
| `Esc` | 关掉弹窗；试玩中就是退出试玩 |

### 试玩

- 点「试玩」或按 `P`，方向键 / WASD 走一步，也可以在画面上往一个方向滑。
- 画布下方会显示当前步数和还没到位的箱子数。
- 箱子推到目标点上变成实心样式；所有箱子都到位就算过关。
- 图里只放人、没放箱子也能走，只是没有过关条件。
- 试玩只是看看这张图能不能走，不写进游戏进度。退出就回编辑，图还在。

### 导入导出

JSON 进出。格式和关卡表一致，导进游戏或从游戏导出都不用额外换算。

## 说明

- 两个编辑器都是纯 HTML + CSS + JavaScript，没有任何运行时依赖，直接从磁盘打开
  即可，不需要本地服务器。
- 人物数据以 `0`/`1` 点阵文本交换（JSON 里每行一个字符串），保持可读、方便对比差异。
- 两个编辑器通过导出的文件互相衔接，也可以各自单独使用。
