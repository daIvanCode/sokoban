地图编辑

左键画、右键擦；按住拖动可以连着画一片

怎么画

六个工具
地面、墙、目标、箱子、人物、擦除。先点工具，再点格子画上去；也可以按 1–6 直接换。
按住拖动
按住左键在格子上拖，可以连着画一整条（墙、地面最常用）。
右键就是擦
右键点格子（或按住拖）把那几格擦回地面，不用先切工具。触屏设备上就选「擦除」。
再点一次取消
墙 / 目标 / 箱子这一格已经是同一种，再点一下就变回地面，改错很快。
人物只有一个
新点一处人物，原来那格自动变回地面。
清空是彻底清空
连外围那一圈墙一起清掉，一张白纸重画。按错了 Ctrl+Z 能撤回来。
尺寸和关卡表一致
固定 16×16，和游戏里 mapdata100.js 的 100 个关卡同尺寸，导进去不用再换算。

快捷键

1–6
切换工具：地面 / 墙 / 目标 / 箱子 / 人物 / 擦除。
↑↓←→
编辑时移动光标（方框跟着走）；试玩时是人走一步。
空格 / Enter
在光标那一格画上当前工具。
Delete / Backspace
把光标那一格擦回地面。
Ctrl+Z
撤销一步；Ctrl+Shift+Z 或 Ctrl+Y 重做。
P
试玩 / 退出试玩。
WASD
试玩时走一步（和方向键一样）。
Esc
关掉弹窗；试玩中就是退出试玩。

试玩

怎么玩
点「试玩」，方向键 / WASD 走一步，也可以在画面上往一个方向滑。画布下方会显示当前步数和还没到位的箱子数。
规则
箱子推到目标点上变成实心样式；所有箱子都到位就算过关。图里只放人、没放箱子也能走，只是没有过关条件。
不写进度
试玩只是看看这张图能不能走，不写进游戏进度。退出就回编辑，图还在。

导入导出

「完成」里拿数据
两种格式各一份，都能复制或下载。
字符地图
# 墙、空格 地面、. 目标、$ 箱子、@ 人物。和 domain/sokoban_state.lua 的关卡表同一格式，写成 { name = M.NAME, map = M.MAP } 就能加进关卡表。
数字格式
1 墙、2 目标、3 箱子、4 人物、0 空地。和 docs/mapdata100.js 一样，直接替换其中的 levels[N]。
「导入」能吃什么
上面任一种都行，也可以只贴一段地图行。比 16×16 大的只取左上角，小的空处按地面补齐。
